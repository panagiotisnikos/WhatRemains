# What Remains

> **A narrative quest mod for Project Zomboid — Build 42**

**What Remains** is a work-in-progress quest and narrative framework for **Project Zomboid Build 42**, designed to bring structured objectives, player choices, progression, and persistent consequences into the sandbox.

The goal is not to replace the survival experience of Project Zomboid, but to give players more reasons to explore, make decisions, cooperate, and survive.

---

## About the Mod

Project Zomboid already creates stories naturally through survival.

**What Remains** builds on that foundation by introducing a quest-driven layer to the world.

Players will encounter objectives and situations that can develop differently depending on their actions, while keeping the experience grounded in the atmosphere and mechanics of Project Zomboid.

The mod is being designed with multiplayer and dedicated server play in mind.

---

## Design Goals

- **Immersive quests** that feel like part of the Project Zomboid world
- **Player choice** with meaningful consequences
- **Multiple paths** through narrative content
- **Persistent progression** across a running world
- **Multiplayer-friendly design**
- **Minimal disruption** to the core survival sandbox
- **Modular architecture** that allows new quests and content to be added over time

## Multiplayer

Multiplayer is a core consideration of the project.

The system is being designed to support persistent quest state on dedicated servers while allowing multiple players to interact with the same evolving world.

Exact multiplayer behaviour is still under development and subject to change.

---

## Development

The project is being developed incrementally.

The current priority is establishing a stable foundation for:

```text
World State
    ↓
Quest State
    ↓
Conditions / Triggers
    ↓
Objectives
    ↓
Player Actions
    ↓
Consequences
```

Narrative content will be built on top of this framework rather than hard-coded as isolated events.
